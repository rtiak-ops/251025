# any型の使用禁止ルール

このプロジェクトでは、型安全性を最大限に高めるため、TypeScriptにおける `any` 型の使用を厳格に禁止します。

## ルール内容
1.  **明示的な any の禁止**: コード内で `: any` または `<any>` を使用してはなりません。
2.  **型推論の活用**: 可能な限り正確な型定義（インターフェース、Type Alias）を作成してください。
3.  **unknown の使用**: 型が不明な場合は `any` ではなく `unknown` を使用し、型ガード（`typeof`, `instanceof`, `axios.isAxiosError` 等）で型を特定してください。
4.  ** eslint の強制**: `eslint.config.js` において `@typescript-eslint/no-explicit-any`: 'error' が設定されており、ビルド時にチェックされます。

## 修正方法
`any` が必要だと思われた場合は、以下の代替策を検討してください：
- APIレスポンス用のインターフェースを定義する
- ユニオン型（`string | number` 等）を使用する
- ジェネリクスを使用して汎用性を持たせる
- 型アサーション（`as Type`）が必要な場合は、十分に安全性を確認した上で行う（推奨はされません）
